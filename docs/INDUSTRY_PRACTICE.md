## Pain points industry still has
- Classifier/model defenses leave residuals: Anthropic 1.4% ASR (browser), 17% FNR on overeager actions (auto mode); OpenAI and Microsoft say injection cannot be fully eliminated. Sources: rows above.
- Published defenses collapse under adaptive attack: 12 defenses (incl. Spotlighting, PromptGuard, Model Armor) were bypassed >90% for most, human red-teaming 100%, despite near-zero originally reported ASR. https://simonwillison.net/2025/Nov/2/new-prompt-injection-papers/
- Approval fatigue: users accept ~93% of manual prompts, motivating sandboxes and classifier-as-approver, which reintroduce probabilistic gating. https://www.anthropic.com/engineering/claude-code-auto-mode
- Provenance loss: Anthropic's classifier cannot tell if an ID was queried or fabricated; it is reasoning-blind and sees only user messages + tool calls. Subagent returns are warn-only. Same source.
- Exfil via allowed channels: vendors patch specific channels (markdown images, URL redaction, origin sets) rather than a general flow policy; sandbox network control depends on domain-allowlist configuration. https://blog.google/security/mitigating-prompt-injection-attacks/ ; https://www.anthropic.com/engineering/claude-code-sandboxing
- Deterministic IFC (CaMeL, FIDES) costs utility (77% vs 84% tasks) or needs hand-written per-tool policies; still research/experimental. https://arxiv.org/abs/2503.18813 ; https://devblogs.microsoft.com/agent-framework/fides/
- Config/policy burden: sandbox safe but "high-maintenance" per new capability; MCP leaves scope/consent design to each server. https://www.anthropic.com/engineering/claude-code-auto-mode ; MCP page above
- Evidence is vendor-internal: attackers are in-house, suites differ across releases, little independent evaluation. https://www.anthropic.com/research/prompt-injection-defenses
